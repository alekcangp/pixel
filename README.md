# Дедупликация, кластеризация и семантический поиск изображений

Консольное приложение для работы с коллекциями изображений: сканирование, поиск дубликатов по перцептивному хэшу, эмбеддинги SigLIP2, кластеризация и семантический поиск. Работает на Windows и macOS, использует GPU (CUDA) с автоматическим fallback на CPU.

## Установка

```bash
pip install -r requirements.txt
```

Для GPU (NVIDIA CUDA) убедитесь, что установлены драйверы и CUDA-совместимый PyTorch. При отсутствии GPU приложение автоматически переключится на CPU.

## Использование

Приложение использует **инкрементальный режим** по умолчанию: повторные запуски обрабатывают только новые и изменённые файлы (определяются по `mtime` + хэшу содержимого). Флаг `--full` принудительно пересчитывает всё с нуля. Все данные хранятся в единой SQLite-базе `storage/images.db` (вместо отдельных JSON/npy-файлов).

### 0. Очистка кэша

```bash
python main.py clear
```

Полностью очищает все таблицы базы данных `storage/images.db` (индекс, дедупликаты, эмбеддинги, кластеры).

### 1. Сканирование файлов

```bash
python main.py scan --path "C:\photos" --ext jpg,png,webp
python main.py scan --path "C:\Users\Yarex" --ext jpg --exclude "Pictures,Documents"
```

Рекурсивно сканирует директорию, фильтрует по расширениям, сохраняет индекс и выводит статистику + топ-10 путей.

По умолчанию исключаются тяжёлые/системные директории (`AppData`, `node_modules`, `.git`, `venv`, `.venv`, `Library`, `Program Files` и др. — список в `config.py`). Параметр `--exclude` добавляет дополнительные директории к стандартным. Директории пользователя вроде `Downloads`/`OneDrive`/`Pictures` НЕ исключаются — их можно сканировать явно.

### 2. Дедупликация

```bash
python main.py dedup
python main.py dedup --move "C:\trash\duplicates"
```

- **Похожие изображения** — по перцептивному хэшу **pHash** (Perceptual Hash) через OpenCV `cv2.img_hash`.
  - pHash использует DCT для вычисления эмбеддинга низкочастотных коэффициентов, устойчив к глобальным изменениям яркости/контраста и сжатию с потерями.
  - Поиск ускоряется **LSH-индексом**: 64-битный хэш разбивается на подблоки, строится инвертированный индекс, проверяются только кандидаты с совпадающим подблоком (векторизованно через numpy). Кластеризация — через Union-Find.
  - Порог Hamming distance задаётся в `config.PHASH_THRESHOLD`.
- **Очистка** — флаг `--move DIR` перемещает все дубликаты (кроме одного «эталонного» файла на группу) в папку `DIR`. Эталонный файл выбирается с **самым ранним mtime** (оригинал обычно старше дубликатов). Без флага `dedup` только отчитывается, файлы не трогая.

Выводит группы дубликатов, сэкономленный объём и топ-10 групп.

### 2.1. Свежие scan + dedup за один проход

```bash
python main.py run --path "C:\photos" --move "C:\trash\duplicates"
```

Команда `run` выполняет сканирование и дедупликацию за один проход (по умолчанию инкрементально). Вместо неё можно явно указать `dedup --path "C:\photos"`, чтобы сначала пересканировать, а затем дедуплицировать.

### 3. Поиск похожих изображений (pHash + LSH)

```bash
python main.py phash-search /path/to/query/image.jpg
python main.py phash-search /path/to/query/image.jpg --top-k 20
```

- **pHash** — перцептивный хэш на основе DCT, устойчив к глобальным изменениям яркости/контраста
- **LSH-индекс** — быстрый поиск кандидатов по совпадению подблоков хэша
- **threshold** — максимальная Hamming distance для считания похожими (`config.PHASH_THRESHOLD`, по умолчанию 2)

### 4. Эмбеддинги

```bash
python main.py embed
```

Загружает модель **SigLIP2** (`google/siglip2-base-patch16-224`), определяет устройство (CUDA → CPU fallback), обрабатывает изображения батчами и сохраняет эмбеддинги.

### 5. Кластеризация

```bash
python main.py cluster
python main.py cluster-hdb
```

Кластеризует эмбеддинги. `cluster` использует MiniBatchKMeans с автоматическим выбором числа кластеров через комбинированную метрику silhouette + Davies-Bouldin и автоименованием через `logits_per_image` модели SigLIP2. `cluster-hdb` использует HDBSCAN + UMAP.

### 6. Семантический поиск

```bash
python main.py search "закат на море"
python main.py search "кошка" --top-k 20
```

Эмбеддинг запроса той же моделью, поиск ближайших по косинусной близости через faiss.

### 7. Web UI (Flet)

```bash
python main.py ui-flet
```

Запускает desktop-интерфейс на Flet с поддержкой сканирования, дедупликации, просмотра кластеров, семантического поиска и экспорта по категориям.

## Структура проекта

```
ss6/
├── main.py                 # CLI-точка входа
├── requirements.txt
├── config.py               # пути, расширения, пороги, параметры
├── app_flet.py             # Flet desktop UI
├── core/
│   ├── database.py         # SQLite-хранилище (схема, CRUD-функции)
│   ├── scanner.py          # этап 1: сканирование
│   ├── dedup.py            # этап 2: дедупликация (pHash + LSH + Union-Find)
│   ├── embedder.py         # этап 3: эмбеддинги SigLIP2
│   ├── clusterer.py        # этап 4: кластеризация (MiniBatchKMeans) + автоименование
│   ├── clustererhdb.py     # этап 4b: кластеризация (HDBSCAN + UMAP)
│   └── search.py           # этап 5: семантический поиск + pHash LSH-поиск
└── storage/                # создаётся автоматически
    └── images.db           # единая SQLite-база данных
```

## Конфигурация

Основные параметры в `config.py`:

| Параметр | Описание |
|----------|----------|
| `DEFAULT_EXTENSIONS` | Расширения по умолчанию |
| `DEFAULT_EXCLUDE_DIRS` | Директории, исключаемые при сканировании |
| `MIN_FILE_SIZE` | Минимальный размер файла в байтах (10 КБ) |
| `PHASH_THRESHOLD` | Порог Hamming distance для pHash (2) |
| `SIGLIP_MODEL` | Модель SigLIP2 |
| `EMBED_BATCH_SIZE` | Размер батча эмбеддингов (16) |
| `EMBED_IMAGE_SIZE` | Размер изображения для эмбеддингов (224) |
| `CLUSTER_MIN_CLUSTERS` | Минимальное число кластеров (2) |
| `CLUSTER_RANDOM_STATE` | Random state для воспроизводимости (42) |
| `SEARCH_TOP_K` | Кол-во результатов поиска (10) |
| `SEARCH_THRESHOLD` | Порог cosine similarity для поиска (0.0) |

## Цикл обработки

1. **scan** → рекурсивный обход файлов, хэш содержимого, сохранение в `images`
2. **dedup** → pHash для каждого изображения, LSH-кластеризация, выделение дубликатов
3. **embed** → SigLIP2 эмбеддинги (исключаются дубликаты и повреждённые)
4. **cluster** → MiniBatchKMeans + автоименование через logits_per_image
5. **search / phash-search** → семантический и pHash-поиск
