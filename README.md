# Pixel

**Локальная дедупликация, кластеризация и семантический поиск изображений на всём компьютере.**

[Русский](README.md) · [English](README.en.md)

> Организуйте тысячи изображений без ручного просмотра папок.
> Сканируйте диски, находите визуально похожие изображения, группируйте их в кластеры, ищите по естественному языку, отбирайте нужные фото и экспортируйте их — всё локально.

![Image Deduplication UI](screenshots/main.png)

## Обзор

**Pixel** — локальное десктопное приложение и CLI для организации больших коллекций изображений.

Вместо того чтобы открывать папки одну за другой, приложение строит единый локальный индекс ваших изображений и обрабатывает их в несколько этапов:

```text
Сканирование
  ↓
Перцептивная дедупликация
  ↓
Эмбеддинги изображений
  ↓
Семантическая кластеризация
  ↓
Визуальный отбор
  ↓
Экспорт
```

Приложение хранит свой индекс и метаданные локально и не требует загрузки изображений в облачный сервис.

## Возможности

* 🔎 **Инкрементальное сканирование** — обрабатываются только новые или изменённые файлы.
* 🧹 **Перцептивная дедупликация** — находит визуально похожие изображения с помощью pHash + LSH.
* 🧠 **Семантический поиск** — поиск изображений по запросам на естественном языке с SigLIP и FAISS.
* 🗂️ **Автоматическая кластеризация** — группирует визуально/семантически связанные изображения с UMAP + HDBSCAN.
* 🖥️ **Десктопный интерфейс** — интерактивная галерея на Flet.
* 🖱️ **Визуальный отбор** — выбор отдельных изображений или целых групп.
* 📦 **Экспорт** — копирование выбранных изображений в папку назначения.
* 💾 **Локальная обработка** — данные изображений и локальный индекс остаются на вашей машине.
* ⚡ **GPU-ускорение** — CUDA на поддерживаемых системах NVIDIA, MPS на Apple Silicon, иначе CPU.

## Как это работает

### 1. Сканирование

Сканер рекурсивно обходит выбранные директории и индексирует поддерживаемые файлы изображений.

Поддерживаемые расширения по умолчанию:

* JPEG / JPG
* PNG
* WebP
* BMP
* GIF
* TIFF

Сканирование инкрементальное и отслеживает метаданные/содержимое файлов, поэтому неизменённые файлы не обрабатываются повторно.

Графический интерфейс может сканировать все доступные диски, при этом системные, кэш, разработочные и другие служебные директории исключаются по умолчанию.

### 2. Дедупликация

Каждое изображение преобразуется в перцептивный хэш (pHash).

Затем используется индекс Locality-Sensitive Hashing (LSH) для эффективного поиска хэшей в пределах настраиваемого порога расстояния Хэмминга.

Текущий порог по умолчанию:

```text
pHash расстояние Хэмминга <= 6
```

Похожие хэши группируются с помощью Union-Find.

На этапе дедупликации можно опционально переместить все файлы, кроме одного из каждой похожей группы, в другую директорию.

> **Важно:** pHash определяет перцептивное сходство. Это не точное побайтовое сравнение файлов.

### 3. Эмбеддинги изображений

Для семантического поиска и кластеризации изображения преобразуются в эмбеддинги с помощью:

```text
google/siglip-base-patch16-224
```

Эмбеддинги хранятся локально и могут переиспользоваться между запусками.

Приложение автоматически выбирает лучшее доступное устройство PyTorch:

```text
NVIDIA GPU → CUDA
Apple Silicon → MPS
иначе      → CPU
```

### 4. Кластеризация

Эмбеддинги изображений понижаются с помощью UMAP и кластеризуются с HDBSCAN.

Реализация также содержит дополнительную обработку больших кластеров и шумовых точек.

Кластеризация автоматически выполняется рабочим процессом десктопа после генерации эмбеддингов.

### 5. Поиск

Семантический поиск принимает запросы на естественном языке, например:

```text
кот на окне
горы на закате
люди на пляже
красная машина
```

Текстовый запрос эмбеддится и сравнивается с эмбеддингами изображений через индекс внутреннего произведения FAISS.

### 6. Отбор и экспорт

Десктопный интерфейс предоставляет галерею для просмотра изображений.

Вы можете:

* выбрать отдельные изображения;
* выбрать все изображения в группе;
* просмотреть изображения в увеличенном виде;
* искать по проиндексированной коллекции;
* просматривать выбранные файлы;
* экспортировать выбранные файлы в директорию.

## Требования

* Python **3.12** (рекомендуется)
* pip
* подключение к интернету для первоначальной загрузки модели

Для семантического поиска, эмбеддингов и десктопного интерфейса требуются PyTorch и модель Hugging Face.

## Установка

Для быстрой установки достаточно скачать и запустить файл установщика для вашей операционной системы. Установщик сам создаст виртуальное окружение Python 3.12, установит зависимости, скачает модель и запустит приложение.

### macOS

Запустите:

```bash
chmod +x install_and_run.command
./install_and_run.command
```

Установщик создаёт виртуальное окружение Python 3.12, устанавливает зависимости, скачивает модель SigLIP и запускает десктопное приложение Flet. Если проект не найден, автоматически клонирует репозиторий с GitHub. Повторный запуск переустанавливает зависимости/модель при необходимости и снова запускает приложение.

> Встроенный установщик `.command` в настоящее время предназначен для macOS. Для Linux используйте процедуру ручной установки ниже.

### Windows

Запустите:

```bat
install_and_run.bat
```

Установщик Windows при необходимости скачивает/настраивает Python 3.12, создаёт виртуальное окружение, устанавливает зависимости, скачивает модель и запускает приложение. Если проект не найден в текущей папке, установщик автоматически скачивает его с GitHub. Повторный запуск того же файла переустанавливает зависимости/модель при необходимости и снова запускает приложение.

### Ручная установка

Клонируйте репозиторий:

```bash
git clone https://github.com/alekcangp/pixel.git
cd pixel
```

Создайте виртуальное окружение.

**Windows — Командная строка:**

```bat
python -m venv .venv
.venv\Scripts\activate.bat
```

**Windows — PowerShell:**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Скачайте модель «изображение-текст»:

```bash
python -c "from transformers import AutoProcessor, AutoModel; m='google/siglip-base-patch16-224'; AutoProcessor.from_pretrained(m); AutoModel.from_pretrained(m); print('Model loaded:', m)"
```

## Быстрый старт

### Десктопное приложение

```bash
python main.py ui-flet
```

Десктопный интерфейс объединяет сканирование, дедупликацию, кластеризацию, семантический поиск, отбор изображений и экспорт в одном рабочем процессе.

### CLI

#### Сканирование директории

```bash
python main.py scan --path "/path/to/folder"
```

#### Принудительное полное пересканирование

```bash
python main.py scan --path "/path/to/folder" --full
```

#### Сканирование с расширениями и исключениями

```bash
python main.py scan \
  --path "/path/to/folder" \
  --ext "jpg,png,webp" \
  --exclude "tmp,cache"
```

#### Изменение минимального размера файла

Минимальный размер файла по умолчанию — **20 КБ**.

```bash
python main.py scan --path "/path/to/folder" --min-size 5
```

Значение задаётся в КБ.

#### Сканирование и дедупликация

```bash
python main.py run --path "/path/to/folder"
```

#### Дедупликация проиндексированной коллекции

```bash
python main.py dedup
```

#### Дедупликация с перемещением дубликатов

```bash
python main.py dedup --move "/path/to/duplicates"
```

Приложение сохраняет один канонический файл из каждой группы похожих изображений и перемещает остальные файлы в директорию назначения.

#### Генерация эмбеддингов

```bash
python main.py embed
```

Принудительная перегенерация:

```bash
python main.py embed --full
```

#### Кластеризация изображений

```bash
python main.py cluster-hdb
```

#### Семантический поиск

```bash
python main.py search "кот на окне"
```

Ограничение количества результатов:

```bash
python main.py search "кот на окне" --top-k 10
```

#### Поиск по визуальному сходству

```bash
python main.py phash-search "/path/to/image.jpg"
```

Ограничение количества результатов:

```bash
python main.py phash-search "/path/to/image.jpg" --top-k 10
```

#### Очистка локальной базы данных

```bash
python main.py clear
```

> `clear` удаляет локальный индекс изображений и сохранённое состояние приложения. Он не удаляет ваши исходные файлы изображений.

## Локальное хранение

Приложение хранит свою локальную базу данных и сгенерированные данные в:

```text
storage/
```

Основная база данных SQLite:

```text
storage/images.db
```

Исходные файлы изображений не копируются в базу данных.

## Производительность и оборудование

Приложение спроектировано для работы без выделенного GPU.

### CPU

Все основные рабочие процессы работают на CPU, хотя генерация эмбеддингов для больших коллекций может быть заметно медленнее.

### NVIDIA

При доступности CUDA PyTorch использует GPU NVIDIA для генерации эмбеддингов.

### Apple Silicon

На поддерживаемых системах Apple Silicon PyTorch использует бэкенд MPS от Apple.

При нехватке доступной памяти GPU реализация эмбеддингов может откатываться к CPU.

## Примечания и ограничения

* pHash предназначен для перцептивного сходства и может группировать изображения, которые не являются побайтово идентичными.
* Порог pHash по умолчанию относительно строгий (`6`) и настраивается в `config.py`.
* Системные и служебные директории исключаются по умолчанию при сканировании.
* Рабочий процесс десктопа автоматически запускает эмбеддинги и кластеризацию после сканирования.
* Стандартный `requirements.txt` устанавливает PyTorch, хотя несколько операций CLI реализованы так, что могут работать без импорта PyTorch.
* При первом запуске семантического поиска/эмбеддингов модель скачивается с Hugging Face.
* Проект local-first, но первоначальная загрузка модели требует сетевого доступа.
* Экспорт копирует исходные файлы, не изменяя изображения-источники.

## Конфигурация

Большинство параметров обработки настраиваются в `config.py`, включая:

* поддерживаемые расширения изображений;
* исключаемые директории;
* минимальный размер файла;
* порог pHash;
* размер пакета эмбеддингов;
* параметры UMAP;
* параметры HDBSCAN;
* лимиты результатов семантического поиска.
